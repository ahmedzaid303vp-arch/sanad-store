# SANAD Store

## تنظيم المشروع

- صفحات الموقع: ملفات `*.html` في المجلد الرئيسي.
- التنسيقات: `assets/css/`.
- JavaScript: `assets/js/`.
- صور الموقع بصيغة WebP: `assets/images/`.

## التشغيل المحلي

يمكن فتح `index.html` مباشرة، والأفضل تشغيل سيرفر محلي من داخل مجلد المشروع:

```powershell
python -m http.server 8765
```

ثم فتح:

```text
http://127.0.0.1:8765/index.html
```

## Appwrite

المتجر الآن واجهة ثابتة. قبل النشر، اربطه بـAppwrite للمنتجات والطلبات وتسجيل دخول المدير وصور المنتجات. خطوات وقواعد الربط موجودة في `APPWRITE_SETUP.md`.

## الهيدر المشترك

كل صفحات المتجر تستخدم `assets/css/site-header.css` و`assets/js/site-header.js`.
هذان الملفان مسؤولان عن المقاسات والأيقونات والبحث والقائمة المتجاوبة؛ لا تضف تعديلات للهيدر داخل تنسيق صفحة منفردة.
الكلاسات `site-*` تعزل الهيدر عن تنسيقات `.hdr` و`.nav` القديمة في ملفات الصفحات.

- ارتفاع الهيدر: 84 بكسل بدءًا من عرض 1280، و72 بكسل تحت ذلك.
- روابط الأقسام تتحول لقائمة صفوف داخل الهيدر على الشاشات الضيقة، وتغلق عند اختيار رابط أو الضغط على Escape.
- البحث في الرئيسية فقط؛ على الموبايل يفتح بزر البحث.
- لا توجد تبعيات خارجية لتشغيل الهيدر، ويعمل أيضًا عند فتح ملف HTML مباشرة.

مهم: المنتجات الحالية محفوظة في متصفحك حسب عنوان الموقع؛ تغيير المتصفح أو الانتقال من `file://` إلى سيرفر بعنوان مختلف لا ينقل هذه البيانات تلقائيًا.
